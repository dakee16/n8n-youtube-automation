# n8n Automation – YouTube Shorts Pipeline

This repository contains an n8n workflow that automates:
- Video ingestion
- Metadata generation using AI
- Google Sheets tracking
- Auto-upload to YouTube Shorts

## 🔧 Tools Used
- n8n
- OpenAI API
- Google Sheets API
- YouTube Data API

## 📁 Workflow
The main workflow is located at: youtube.json


## 🚀 How to Use
1. Clone the repo
2. Import the workflow into n8n
3. Add your credentials in n8n
4. Update environment variables
5. Activate the workflow

## 🔐 Credentials
All credentials are handled via n8n's credential manager.
See `needed_APIs` for required variables.

## 📌 Notes
This workflow is shared for demonstration purposes.
